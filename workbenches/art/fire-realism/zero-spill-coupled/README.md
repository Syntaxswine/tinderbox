# Zero local spill causal control

PRIMARY commit `344202f12ea2756508f60e14de393cce0b83c737`,
`docs/proposals/zero-spill-causal-control.md`, authorizes this additive source
candidate from exact34af. That proposal remains in PRIMARY, not this branch.

The wrapper delegates the exact coupled factory and aliases its prepare,
evidence and audit functions. Its one original store, 66 old modules and 193
resource records remain. Two new modules make a 68-module closure; no copied data.

Before mutation, every one of 92 distinct private materials must have the entire
6,839-byte coupled fragment, original vertex and uniform6. The sole directly owned
PointLight must match color 0xff8d35, position [5.5,.3,8.5], distance 4.5, decay 2 and
initial intensity 0. Scene/environment lights are never searched or changed.
Only this light's intensity is forced0 after each delegated update. Arguments,
receiver, results, original root and original lifecycle are preserved. Reset and
dispose follow the delegate; failures retire privately and keep original,
suppression and cleanup causes. Disposal is not retried. Diagnostics distinguish
requested intensity, applied zero, last operation and the still-allocated light. If cleanup throws, actual root retention and the
delegate's count remain separate; no successful GPU retirement is inferred.

All shader bytes/uniforms, FP/j6/k6, raw fields, smoke, associated blend, geometry,
depth, masks, legibility, source clocks, environment and underlay stay fixed.
Removing this wrapper restores the unchanged delegate and ordinary spill; this
is a source/state inverse, not a reversible GPU/program-cache promise.

Run only the small source/string/plain-VM-mock gate from the repository root:

```
node --experimental-vm-modules workbenches/art/fire-realism/zero-spill-coupled/check.mjs
```

No actual factory/data namespace, prepare/audit, renderer, GPU, helper or 193
resource replay runs. Four syntax checks cover the two runtime modules plus
source.mjs/check.mjs. Parent attributes append only three literal filename LF
rules, preserving every old byte/rule.

This is an ablation, not a final unlit product, useful R or cost optimization.
Zero intensity does not establish zero GPU work: the light remains allocated.
If only the halo darkens while the body stays filled, spill alone is refuted as
the morphology fix. Better rooted contrast would identify a confound, not satisfy
native/global8/28/optimized/hardware20–33% gates. No fitted replacement light,
gain/palette/field/bake change or promotion follows. Raw97/50positive,98zero and
all admission/reference/inputE flags remain false. ROOT owns independent source
review and any later native comparison.
