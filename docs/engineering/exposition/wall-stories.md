# One-through-five-story wall options

The user's later cross-game asset compatibility requirement supersedes the earlier 3.2m-per-story presets. The current kit repeats unchanged native Animal Factory Tactics / Farmyard Commando wall units: 1m wide, 2m high, .16m thick, with 2.12m floor origins and .12m intervals. Native doors remain 1 x1.65m, .12m thick. See [native-scale evidence and verification](native-scale.md) and [the shared contract](contract.md).

| Stories | Native facade top (m) |
| --- | --- |
| 1 | 2 |
| 2 | 4.12 |
| 3 | 6.24 |
| 4 | 8.36 |
| 5 | 10.48 |

These are the original asset-system dimensions. They are not calibrated measurements of a particular 1893 facade. New historical skins use the same templates, physical texture density and floor origins so they remain transferable to later games. Older diagnostic screenshots from c3b7ec4 show superseded resized presets and must not be used as export templates.
