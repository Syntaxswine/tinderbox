## Limits and remaining gate

The flat contact kernel proposes horizontal movement; actual height changes and newly raised headroom are decided by the native validator. If such a segment is unsafe it stops at a safe prefix instead of inventing an alternative shoulder. More than 8,192 projected contact primitives in one local query produces a bounded diagnostic and no motion, rather than simplifying native geometry.

This checkpoint adds no foliage, UI, physical art, native body rescaling or new fire behavior. The focused results and pinned matrix are CPU evidence. Repository/build/release/nested-package checks and actual normal-zoom mouse/keyboard review must run on the coherent checkpoint after the architect's next gate.
