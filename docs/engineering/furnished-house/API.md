# Furnished Hopkins 15 workbench API, version 1

Standalone candidate for architect contract `3596f41cbeb0a85c648c44b789a838ed5a8dc139`, milestone 18. Production code does not import this workbench. The artist owns `art.js`, `house-data.json` and its export recipe. The frozen second trial at `9b521a20d888a92197c75f03fbb75f762bf4ba67` is retained byte-for-byte under `upstream/`; `intake.json` records hashes. Its scene is evidence, not the furnished scene compiler.

Coordinates are local **metres, X/Z ground, Y up**. This explicitly converts the source trial's `i/j` ground and `k` vertical convention. The native 1 × 1 × 2.12 m structural module is unchanged. Thermal cells initially measure .5 × 1.06 × .5 m; their origin is `[0,.48,0]`. Geometry remains at its actual fractional coordinates.

`createFurnishedHouseArt(THREE, {renderer, data})` returns (possibly asynchronously) `{root, update(frame,view), diagnostics(), dispose()}`. Renderer and camera are borrowed. Disposal retires only resources created by the factory.

The artist's version-1 export contains `prefabId`, `buildingId`, `sourceHashes`, `levels`, `surfaces`, `openings`, `furnitureParts`, `items`, `stores`, `render` and `navigation`. A surface has a stable `id`, `kind`, `level`, exact `triangles`, `normal`, `thickness`, physical `material`, `sourceMeshBindings` and declared finite `fuelClass`/`fuelAmount`. Floors include the inferred .12 m closed slab face and the actual stair void. Furniture parts retain their actual local `matrix`, `bounds`, `itemId`, physical material and separate `finish`. Stores refer to existing fuel parts so their amount is introduced once. No room-centre contents are generated.

`createTrial(data, options)` owns fixed ticks, commands, fuel and heat accounting. `command({tick,type,...})` queues a tick-stamped interaction. `step(count=1)` advances whole 1/30-second world steps. `frame({full=false})` produces retained-state changes. `snapshot()` and `replay()` are serializable. A reset starts a new simulation; it does not run timers backwards. `createClock(trial)` consumes elapsed real seconds and preserves its unprocessed accumulator, with explicit world speed. It never discards world steps.

Frame fields: `version`, monotonic `revision`, integer `tick`, `worldTime`, `full`, `boundaries`, `supports`, `items`, `falls`, `events`, `metrics`, `fireSamples`, `tombstones`, optional diagnostic `occupancy`. Initial and reset frames are full; subsequent frames merge stable-ID changes and removals. Each boundary/support carries `id`, `sourceSurfaceId`, exact clipped `triangles`, `intact`, `openFraction`, `charFraction`, `heatFraction`, `fuelFraction`. Patch geometry, collision and transmission share one canonical state. An opening command changes that state, including its broken pane/door presentation and shadows.

Items carry `id`/`itemId`, actual pose (`position`/`quaternion` or `matrix`), `intact`, `remainingFraction`, `charFraction`. Falls retain the same fuel/item IDs and add actual pose, `flame`, `smoke`, `ignitionTime`. Events are simulation facts with integer tick/time. Fire samples retain the published structural fields `id,buildingId,part,x,y,z,nx,ny,nz,area,flame,smoke,ignitionTime`, plus `sourceSurfaceId` or `itemId`; floor samples carry exact `floorFootprint` triangles and bounded `floorRadius`. Art must not derive ignition, failure, fuel or collisions.

Review correction: `parts` is a retained collection keyed by the exact `data.furnitureParts.id`, containing `{id,itemId,intact,material,remainingFraction}`. It retires only the exhausted physical component. Unfueled iron/stone stays intact. A whole item retires only when all its physical parts retire. Items keep their source render pivot; support release uses exported actual support IDs, and swept landing uses the component footprint's centre/corners. Landing events distinguish the render `position` from physical `contactPosition`. Live falls are accompanied by explicit `{collection:'falls',id}` tombstones on landing/escape. Heating/charring/cooling patches are published before ignition as well as during combustion.

The fixed-clock adapter optionally accepts explicit `worldScale` and `playerScale`. The powder control borrows the published values .35 and 1.5; ten active seconds produce 3.5 world seconds and 15 player seconds. Wind and fire consume the world clock. Playback speed multiplies all clocks explicitly and is independent of this gameplay relation. No manual drug control is introduced in the game or this workbench UI.

View: `{mode:'exterior'|'auto'|'cutaway'|'xray',level:0|1,camera,observer?,sampleWind?}`. Observer is `{x,y,z,height}`. Cutaway changes presentation only. X-ray consumes actual `occupancy` records. The Ashland-specific frozen wind field must not be applied to Hopkins geometry. Wind is an injected metre-coordinate sampler with declared source metadata.

Prototype tuning, source defects, physical passage measurements, controls, budgets and acceptance results are recorded separately from this interface. A pushed API checkpoint is not completed gameplay or production promotion.
