# Furnished Hopkins 15 workbench API, version 1

Standalone candidate for architect contract `3596f41cbeb0a85c648c44b789a838ed5a8dc139`, milestone 18. Production code does not import this workbench. The artist owns `art.js`, `house-data.json` and its export recipe. The frozen second trial at `9b521a20d888a92197c75f03fbb75f762bf4ba67` is retained byte-for-byte under `upstream/`; `intake.json` records hashes. Its scene is evidence, not the furnished scene compiler.

Coordinates are local **metres, X/Z ground, Y up**. This explicitly converts the source trial's `i/j` ground and `k` vertical convention. The native 1 × 1 × 2.12 m structural module is unchanged. Thermal cells initially measure .5 × 1.06 × .5 m; their origin is `[0,.48,0]`. Geometry remains at its actual fractional coordinates.

`createFurnishedHouseArt(THREE, {renderer, data})` returns (possibly asynchronously) `{root, update(frame,view), diagnostics(), dispose()}`. Renderer and camera are borrowed. Disposal retires only resources created by the factory.

The artist's version-1 export contains `prefabId`, `buildingId`, `sourceHashes`, `levels`, `surfaces`, `openings`, `furnitureParts`, `items`, `stores`, `render` and `navigation`. A surface has a stable `id`, `kind`, `level`, exact `triangles`, `normal`, `thickness`, physical `material`, `sourceMeshBindings` and declared finite `fuelClass`/`fuelAmount`. Floors include the inferred .12 m closed slab face and the actual stair void. Furniture parts retain their actual local `matrix`, `bounds`, `itemId`, physical material and separate `finish`. Stores refer to existing fuel parts so their amount is introduced once. No room-centre contents are generated.

`createTrial(data, options)` owns fixed ticks, commands, fuel and heat accounting. `command({tick,type,...})` queues a tick-stamped interaction. `step(count=1)` advances whole 1/30-second world steps. `frame({full=false})` produces retained-state changes. `snapshot()` and `replay()` are serializable. A reset starts a new simulation; it does not run timers backwards. `createClock(trial)` consumes elapsed real seconds and preserves its unprocessed accumulator, with explicit world speed. It never discards world steps.

Frame fields: `version`, monotonic `revision`, integer `tick`, `worldTime`, `full`, `boundaries`, `supports`, `items`, `falls`, `events`, `metrics`, `fireSamples`, `tombstones`, optional diagnostic `occupancy`. Initial and reset frames are full; subsequent frames merge stable-ID changes and removals. Each boundary/support carries `id`, `sourceSurfaceId`, exact clipped `triangles`, `intact`, `openFraction`, `charFraction`, `heatFraction`, `fuelFraction`. Patch geometry, collision and transmission share one canonical state. An opening command changes that state, including its broken pane/door presentation and shadows.

Items carry `id`/`itemId`, actual pose (`position`/`quaternion` or `matrix`), `intact`, `remainingFraction`, `charFraction`. Falls retain the same fuel/item IDs and add actual pose, `flame`, `smoke`, `ignitionTime`. Events are simulation facts with integer tick/time. Fire samples retain the published structural fields `id,buildingId,part,x,y,z,nx,ny,nz,area,flame,smoke,ignitionTime`, plus `sourceSurfaceId` or `itemId`; floor samples carry exact `floorFootprint` triangles and bounded `floorRadius`. Art must not derive ignition, failure, fuel or collisions.

Review correction: `parts` is a retained collection keyed by the exact `data.furnitureParts.id`, containing `{id,itemId,intact,material,remainingFraction}`. It retires only the exhausted physical component. Unfueled iron/stone stays intact. A whole item retires only when all its physical parts retire. Items keep their source render pivot; support release uses exported actual support IDs, and swept landing uses the component footprint's centre/corners. Landing events distinguish the render `position` from physical `contactPosition`. Live falls are accompanied by explicit `{collection:'falls',id}` tombstones on landing/escape. Heating/charring/cooling patches are published before ignition as well as during combustion.

The fixed-clock adapter optionally accepts explicit `worldScale` and `playerScale`. The powder control borrows the published values .35 and 1.5; ten active seconds produce 3.5 world seconds and 15 player seconds. Wind and fire consume the world clock. Playback speed multiplies all clocks explicitly and is independent of this gameplay relation. No manual drug control is introduced in the game or this workbench UI.

Support review addition: `falls[].geometry` supplies exact clipped `triangles`, `solidTriangles`, `normal`, `thickness`, `sourceSurfaceIds` and `boundaryIds` for a native-cell batch of detached structure. Contact offsets come from the actual solid bottom. A mechanically detached patch keeps its original fuel ID, amount, ignition time and burn profile; it is distinct from the 15% ember remainder after material burnout. The approved stair-flight approximation requires both actual lower and upper landings.

`rubble` is a retained collection created on actual landing, after the corresponding `falls` tombstone. Each record carries `{id,fuelIds,position,triangles,floorFootprint,supportBoundaryId,sourceSurfaceIds,thickness:.01,nonBearing:true,kind,phase,remainingAmount,remainingFraction,heatFraction,flame,smoke,ignitionTime}`. Its footprint is projected from the actual fallen piece and clipped to the actual landing support. It is a declared shallow, nonbearing layer below the existing .025 m foot-clearance tolerance, not a full-height obstacle or a rigid-body stack. It persists as inert ash when fuel is spent, with flame/smoke zero; it can fall again if its actual support disappears. Transfers emit `rubble` tombstones and never duplicate their fuel IDs. Inert unheated falls have `ignitionTime:null`, flame 0 and smoke 0.

Preheat samples have flame 0, a finite presentation start in `ignitionTime`, and `ignited:false`; only ignition events establish actual ignition. Sound sheets emit on their exposed side. An underside floor sample uses negative Y normal and the actual underside elevation. Window `vent:true` samples reference `openingId` and actual outward local heat flux through the canonical open pane; this visualizes already-budgeted transport and creates no fuel or additional heat.

Late-frame correction: loose/airborne samples omit `sourceSurfaceId` and retain `originalSourceSurfaceId` solely as provenance. They publish the current `fallId` or `rubbleId`, actual `supportBoundaryId` and landed `floorFootprint`; current physical ownership takes precedence over the retired source patch. Rubble also carries its original `fallId`. A coalesced frame may skip an entire intermediate landing/retransfer. Merge current rubble, retire every tombstoned obsolete flight without waiting for a historical landing, then map effects from the current pose/footprint. `falls` and `rubble` enumerate their current live records; same-ID reactivation supersedes its old tombstone before publication. Residue removals must only clear a fuel lookup if that lookup still points to the removed residue, preserving a newer landing for the same fuel. Camera-only/paused draws are empty retained deltas at the same revision, so an empty collection is never an implied clear command.

A landing requires nonzero overlap of the fallen hull with the actual contacted solid face. This includes an existing fitting top independently of its support-graph role. A seam contact may select a real coplanar neighbouring face under the same hull, at the same first-contact height. If there is no supported area, the line/corner contact is a graze and the fragment continues falling to the next real bearing face. The rubble binds to that selected boundary and its exact clipped footprint; retirement of that boundary releases it again. This adds no bearing, geometry or fuel and does not relocate a loose orphan to hide a failed contact.

Manifest preparation is shared: call `prepareFurnishedData(raw)` from `prepare-data.js`, or use `trial.scene.data`, for the artist factory. The browser runner already does so. Runtime adapter version 1 binds the real native chimney shaft and cap as one inert item on six measured local roof hosts; it removes their static duplicate surfaces. It preserves their original shape/size and adds no lower stack or fuel. Losing the roof hosts starts a cold, rigid translation to the first actual support. Both art and physics must consume the prepared manifest. Replay metadata records this adapter and its source bindings.

Fitting fragments use their actual clipped source exterior, rather than retaining a complete source collider in each thermal fragment. Cut fragments disable watertight parity; intact whole native solids retain it. Declared host connections are directed from bearing to fitting, locally filtered by the exported 15 mm joinery tolerance; ornamental fittings cannot become structural bridges. Actual adjacent fragments of the same component stay connected.

For isolated measurement, `window.__furnished.sampleStep(count=1,{present:true})` returns simulation, presentation and render CPU milliseconds directly, plus draw/active counts. `data` exposes the prepared shared manifest. Stop automatic rendering first with `setAutoRender(false)`; the normal UI still uses its animation loop.

View: `{mode:'exterior'|'auto'|'cutaway'|'xray',level:0|1,camera,observer?,sampleWind?,windMetadata?,effects?,lightingMode?}`. Observer is `{x,y,z,height}`. Cutaway changes presentation only. X-ray consumes actual `occupancy` records. The Ashland-specific frozen wind field must not be applied to Hopkins geometry. Wind is an injected metre-coordinate sampler with declared source metadata. The runner also supplies `trial.windMetadata` so the artist can identify the known ambient/calm bounds; an arbitrary sampler without established bounds cannot be assumed bounded for culling.

Milestone 19 adds presentation-only `effects:{flames,smoke,lighting}` with known boolean keys; omission defaults all three on. Fire lighting means cast illumination, separate from flame self-emission and ambient night illumination. The page's single preference store persists under `tinderbox.furnished-house.effects.v1`, survives replay reset and is shared by the native controls plus `window.__furnished.effects()`/`setEffects(patch)`. A changed mask redraws paused state immediately without advancing clocks or physics. Disposal unmounts/unsubscribes the page's effect bindings. Detailed store semantics and bounded evidence are in [effect-settings-runtime.md](effect-settings-runtime.md).

The optional `lightingMode:'local'|'building'` selects reference local lighting or the artist's bounded building-glow comparison. Omission/invalid input uses `local`. `window.__furnished.lightingMode()`/`setLightingMode(mode)` and `?lighting=building` expose this page-only choice, preserve it through replay reset and never store a fourth boolean. Mode changes redraw the same authoritative state/time; the UI remains three checkboxes.

Prototype tuning, source defects, physical passage measurements, controls, budgets and acceptance results are recorded separately from this interface. A pushed API checkpoint is not completed gameplay or production promotion.

Milestone20 adds an explicitly selected numerical grass fixture: `?grass=on` builds the additive data before art; omission remains the original data. Reset retains the selected fixture. `grassFixture()` returns its detached metadata. The shared replay command is extracted unchanged into `replay-data.js`. `grassFrame` adds a retained `grassGround` collection with stable boundary/source/fuel IDs, clipped XYZ triangles and authoritative phase/fuel/char/heat/fire fields; `full` resets, deltas upsert, spent grass remains ash and paused/camera deltas preserve it. Grass samples are explicitly `grass:true`, part ground, buildingId furnished-exterior-grass, separate from house storeys/lighting aggregation. Geometry, masks, provenance and limitations are [documented separately](../furnished-house-grass/README.md). Artist rendering and combined visual acceptance remain coordinated assignments.

Milestone21's opt-in research hook is `createTrial(data,{radiationSelection})`; omission/null preserves the original policy. `select({sourceId,position,range,count})` returns ordered `{id,position}` reference targets, resolved and position-checked against live scene cells. Optional `observeRay({tick,sourceId,targetId,position,area,capacity,incidence,weight,transmission})` records live construction values; its return is ignored. Area/incidence, tracing, invalidation, queues and heat accounting remain live. The bounded initial-reference adapter and its evidence are [documented here](../fire-receiver-selection/README.md); the normal page never enables this hook.
