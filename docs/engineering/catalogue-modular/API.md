`?catalogue=modules&execution=reference` selects the full-registry execution loops. The default execution cache preserves registry order while visiting preheat candidates from active cells plus every charred or nonpositive-threshold fuel. Burning and loose-fuel candidates retain original registry order. Heated glazing and burning-boundary retirement candidates sort in original boundary order; doors retain live boundary references.

Fuel accounting retains exact sequential prefix accumulators. Amount, ignition, falling, loose-state and birth transitions invalidate the earliest affected registry slot; actual fuel records are reread from there in their original addition order. No subtraction identity, regrouped sum, changed precision or tolerance replaces the independent finite ledger. Metrics/fire samples also cache within a native tick. Static item bearing results invalidate on index revision/count, position and current landing identity. Smoke portal membership caches actual boundary references, invalidating on boundary/opening membership or declared vent changes; pose, permeability, retirement, live sources and visibility are read normally. Complete-state controls cover early/late changes, cooling/smoke, falls/spills/escape, glazing, dynamic fuel, door/membership changes and pending radiation. Ground publication reuses unchanged immutable rows and exposes actual deposited oil/spills to the original trail/fire channels. No offscreen heat is deleted.

Prepared instance data is already qualified and in world coordinates. Each renderer receives only its owned physical records, including generated records and tombstones.
