## Reusable implementation

`src/content/shared-map-source-preparation.js` preflights complete source owner
identities, original part/quantity/finish/mode/range/overlay and independently
approved witnesses through the existing admission module. Only explicitly named
pending source contacts and unreviewed derivation plans may remain unresolved
during this distinct source phase. Unknown/changed source authority refuses
before a load or transform. The selected original-buffer budget must fit the
existing registry; blueprint buffers acquire that same registry's reserve.
Any capacity failure is a named boundary, with no second cache or raised cap.

The preparation consumes the existing compiled host's one decoded model and
source geometry owner. It borrows each selected original once through its one
query registry, uses the existing component and blueprint derivation, and
validates complete canonical fuel/finish allocation. It never constructs a
producer, native world, support graph or clock. A `WeakSet` prevents another
preparation of that owner. Cleanup releases blueprint/provider references,
pins and the registry. The existing approved-projection preparation routine
was extracted from `shared-map-inputs.js` and shared; original host behavior
is covered by the same accepted adapter controls.

Source mapping selects only the named original primitive/component and its
actual blueprint facet or existing native-panel projection. Each own point and
selector remains unchanged. It uses the existing grid/EPS/canonical source loop
and does not clamp a cell, search for another face, merge two witnesses or invent
native record authority. Proposed plans keep `proofRef:null` and unborn native
IDs null: this packet does not approve its own output or alter runtime policy.

The source world table is persisted before blueprint/mapping work so a later
boundary cannot require a second transform merely to recover these inputs.
`selected-blueprints.json` persists the already derived arrays as evidence.
`proposed-plan.json` and `mapping.json` preserve every original ordinary parent,
including unproved/outside alternatives. Other additions remain uninstalled.
