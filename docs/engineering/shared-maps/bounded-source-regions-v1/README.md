This is saved-data grouping evidence for the [bounded source proposal](../bounded-source-regions-v1.md), authority `ea0bb3db15b275513f48df6e00f255438610462e`. It consumes the exact saved v2 JSON and reads pinned current source text. It neither imports the compiler/simulation nor changes runtime/asset/export files.

`group-saved.mjs` assigns all 4,132 original roof fragment IDs by encoded cell, partitions all 33,558 directed edge ranks, counts local pristine components/ports, and exhausts all 131,600 relevant native grid centres for 2 m and 4 m regions. It also counts the conservative potential descriptor catalogue, including groups without saved exterior geometry. It writes `grouping.json` and `input-pins.json`, review evidence rather than a runtime dataset. No triangles or fuel allocations are exported.

`verify.mjs` independently accumulates each region onto query centres, checks the frontier maxima and original membership hashes, recounts all witness edges, and verifies all 53 raw files from the prior v1/v2 manifests plus current source inputs. It writes `verification.json`. These are static graph/spatial counts, not timing observations or native physics tests.

Run both commands from the repository root with the installed Node executable. They are finite foreground analysis commands with no port, trial, native scene, renderer, profiler or retained helper. The saved native observations and their spent markers remain unchanged. See the proposal for stock certificates, closed-volume query semantics and all future implementation gates; these are not proved by grouping alone.
