zero watched-ID counters only showed cleared tracking/guarded callbacks, and
are not reused as unsubscribe proof.

`index.watch`. Per-boundary/callback registration counts preserve the previous
single-notification behavior for duplicate registrations and retain independent
owners. Existing consumers can ignore the new handle. The source graph invokes
only its own handles during disposal/reset; the trial disposes the owned graph.

callback is never delivered again while an independent subscriber still receives
the same boundary's notification. Repeated unsubscribe/disposal and legacy
consumers pass. This successor changes `geometry.js` as a third production path
and is **not remeasured**.
