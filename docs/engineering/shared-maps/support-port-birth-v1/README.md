adapters, following the architect's explicit checkpoint instruction. Base is

The disabled `original-support-ports.js` consumes explicitly supplied original
parts and authoritative fragment/face/component/native-record identities. It
does not build a New York input, import a live factory, install an asset, emit
fuel/render objects or alter the accepted receipt bridge.

The core binds physical ports once to an original part, connected surface
component, primitive, geometry point and supplied original native record/cell.
Distance/ties are deterministic and recorded. Strict embeds require a common
actual original interior witness and an uninterrupted original path to the
chosen port. The original collision predicate rejects a witness inside a void.
Bearing ports use the unchanged native contact operation. Retired original
owners cannot be replaced by a same-cell sibling or a nearer survivor.

Actual surviving fragment contact provides material continuity within an
original part/component. A whole cold-parent node cannot bridge a retired gap.
Each fitting requires both fixed lower ports, supported independently without
its fitting/upper/descendants, and an actual surviving material path between
its two child ports. The upper dependency is directed. Detected old directed
descendant paths are reported. Roof role remains unchanged. The prototype uses
the existing binary support approximation, with no stress/volume solver.

Evaluation borrows caller-owned authoritative fragments for that call and
returns scalar identity/status evidence; it retains no generation-born geometry.
Reset advances generation and rejects stale expected generations. Disposal
releases the original binding tables. The component helper enumerates exact
shared-edge surface components; full New York material-component normalization
has not been established by this checkpoint.

## Exact core input

`createOriginalSupportPorts({parts,bonds,requirements=[],anchors=[]})` consumes
the following records. Coordinates and triangle indices refer to the same
original physical part in emitted world coordinates. The constructor freezes
the supplied original records; it does not load or transform source assets.
The current prototype ceilings are 14,000 parts, 20,000 bonds, 65,536 fragments
and 400,000 original triangles. Full New York readiness under these ceilings has
not been established.

| Record | Required fields | Optional fields / meaning |
| --- | --- | --- |
| Part | `id`, `ownerId`, `triangles` (nonempty array of three finite XYZ points per triangle) | Source metadata such as `role` is retained unchanged. Components are derived from exact shared triangle edges, ordered by the first original triangle. |
| Bond | Unique `id`, `kind`, `direction`, `parent`, `child` | `direction` is `parent-to-child` or `symmetric-structural`. `fixed-embed` selects the strict common-interior test; other kinds use the original bearing/contact path. |
| Each bond endpoint | `partId`, `point` (finite XYZ witness) | `primitives` restricts the original triangle candidates; otherwise all are considered. `nativeRecordId` and `cell` (XYZ cell tuple) fix the native owner. Native liveness requires an exact nonempty native record ID; a supplied cell must also match. Cold liveness does not use the native record ID. |
| Requirement | Unique `id`, `ownerId`, exactly two distinct lower `portIds`, `upperBondId` | Both lower bonds must enter this fitting and the directed upper bond must leave it. |
| Ground anchor | `partId`, `elevation` | `component` optionally restricts the original component. Only caller-supplied original ground anchors are used. |

Each fixed endpoint is resolved at construction to `partId`, `ownerId`,
`component`, `primitive`, closest original surface `point`, `distance`,
`originalWitness`, `nativeRecordId` and optional `cell`. Selection is over the
original geometry, before evaluating any surviving fragments.

`evaluate({revision,fragments,expectedGeneration,bornRecordIds=[]})` requires a
nonnegative safe-integer revision. `expectedGeneration` defaults to the current
generation. Each fragment requires unique `id`, `partId`, matching `ownerId`,
original `component`, nonempty original `primitives` and actual surviving
`triangles`; use `mode:'cold'` or `mode:'native'`, `recordId` and the matching
`cell` for the selected view. The triangles must already have their authoritative
original face/component provenance. This core does not derive that mapping from
native face numbers. `bornRecordIds` selects native fragment births only.
