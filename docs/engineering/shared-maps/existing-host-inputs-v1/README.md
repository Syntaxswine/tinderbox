# Existing-host input factory and metadata admission

Worker candidate from `bb60f1fede4e3a6bd8b56adb38314db6a010fadf`, implementing
the architect's accepted-kernel follow-up at `89df5eb9` and the later source-root
approval at `ec17945b`. Ordinary visits/default mode are unchanged. This delivery
does not enable a map, publish Pages or establish rendered acceptance.

The implementation is in `src/content/shared-map-admission.js` and
`src/content/shared-map-inputs.js`. `compileSharedMap` calls its optional
`inputFactory({model,sources,signal})` after exactly one existing decode and
source-owner creation. `createSharedMapRuntime` awaits `compiled.prepareInputs()`
before invoking the existing runtime. Loader/runtime injection permits synthetic
lifecycle checks without a renderer or second gameplay host.

The factory captures a descriptor and independent review policy. Its metadata
report distinguishes `METADATA_ADMISSION`, later `SOURCE_VALIDATION`, and native
installation. A `MapInputNotReadyError` carries `code: MAP_INPUT_NOT_READY` and
the report. Unproved roots, unknown modes/ranges/overlays/caps, changed quantities
or projection identity, unmapped endpoints, and cache violations reject before
source expansion. Unborn native IDs are null, as expected; a derivation plan is
required instead of prematurely invented native authority.

After preparation, each registry binding pins its admitted original parts once.
The existing source-blueprint builder borrows those buffers. Producer, query and
support setup use the same originals/cache, with blueprint and producer buffers
charged to that registry. Producer creation is lazy until its existing
coordinator reserves its input. The 192-shape /65,536-triangle combined budget
and 24-shape /8,192-triangle fallback reserve remain unchanged. Two regional
parts, 320 total descriptors and 4,096 cells/part remain the regional limits.
Temporary clipped fans use a conservative seven-triangle bound per original
triangle/cell. Incomplete blueprint plans are explicitly an incomplete estimate,
never a cache-fit certificate. The synthetic 64-cell /256-input-triangle check
is an experiment bound, not a newly imposed production whole-owner policy.

The coordinator rejects out-of-cohort owners before source lookup or birth.
Original ordinary bonds remain alternatives; only the explicitly declared two
fixed ports form the fitting's ALL requirement. Both reviewed roots are traced
independently with fitting/upper/descendants excluded. Approved mechanical mounts
require their exact independent tuple; a provenance reference cannot invent one.
An endpoint names its own original point, primitive/component, selector when
applicable, exact blueprint suffix, source-plane projection and cell. The
factory validates that derivation against the shared original geometry, including
the existing native-panel projection. Genuine receipts later bind fixed native
records; the accepted core retains exact retirement and no-retarget semantics.

Reset disposes the old registry binding, producer, pins and blueprint/provider
references before binding the same decoded model again. Visit failure/abort and
compiled disposal release the session. Late projection loads cannot append after
abort/disposal. An old registry's repeated disposal cannot release a newer
binding. No helper, server, port or watcher is retained.
