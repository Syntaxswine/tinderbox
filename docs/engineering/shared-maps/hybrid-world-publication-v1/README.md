## Runtime seams

| Seam | Contract |
| --- | --- |
| `compileSharedMap(...,{internalHybrid})` | Explicit `mode:'hybrid-world-v1'`, pinned `sourceRevision`, `ownerModes`, genuine `producer`, complete `querySources` and original `support` definition. Normal callers omit it. |
| `createSourceActivation` | Selects the coordinator only with that internal mode. `ensurePoint`/`beforeStep` use the existing radiant range; a failed regional owner cannot become a whole birth. |
| `createHybridWorldPublication.prepare({whole,receipts,retireRecords,expected})` | Stages all participants, checks current publication/index revision and private receipt liveness, then publishes one generation/revision. Stale stages dispose without birth. |
| `createTrial.prepareSources` | Uses unchanged whole compilation or privately authenticated regional admission. Regional receipts enter the existing cells/fuels/index without recompilation or another trial. Arbitrary partial inputs still fail. |
| Physical index publication lease | Seals captured installs before mutation, blocks reentrant publication/query/tick reads and defers ordinary observers until all participants are current. Normal index retirement synchronizes regional/support state before ordinary observers. |
| Source query registry | Exact original query geometry, cold/native/retired masks, body sweep and ray queries share one cache, including the fallback allocation. Whole claims remain supported. |
| Source carrier ledger | Same account for canonical cold reserve, whole/regional transfer, local signed clipping allowances and trial-owned consumption/falling/escape. Retirement never refills cold reserve. |
| Original support adapter | Borrows pinned static originals, uses finite positive current material, maps original components/primitives and keeps exact fixed source surface/cell/record bindings. Retired gaps cannot be bridged by a whole cold parent or a replacement sibling. |

Stages expose `validate/publish/dispose`; publication views are bounded metadata,
not geometry or thermal snapshots. Explicit views can be `release`d; disposal
invalidates stages/receipts and advances the producer epoch. Reset is normal
dispose/recreate of one trial, not concurrent worlds or a new clock.

ALL fittings still need both independently rooted original lower ports, connected
surviving fitting material and the directed upper dependency. The optional
`approvedMounts` input accepts only an exact explicitly supplied assembly tuple
with provenance, original gap and parent-to-child direction. The synthetic mount
positive/negative checks do not register production mounts or new earth anchors.
