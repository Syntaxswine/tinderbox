# Live place route review

Serve the combined source checkout through the architect's existing finite preview helper. Open `/workbenches/places/`. This page uses `startApplication`, the real UI, selected native animal, real source sections and actual WebGL runtime. It creates no alternate renderer, simulation or art. Review tooling and route evidence are excluded from the public build. This coding branch expects the architect to combine the exact UI candidate; it does not copy UI-owned files.

For code/package verification before architectural reconciliation, `node tools/assemble-places-review.mjs --ui=<exact-approved-SHA>` creates a private generated source snapshot under ignored `artifacts/TB-024/`. It overlays only the immutable UI closure without changing tracked UI files or another worker checkout. `review-intake.json` records every UI source hash and working-code byte hash. Run build/release/HTTP checks from that generated directory after the access and medicine intake is ready. This artifact is not a Git worktree, candidate promotion or deployed package, and it does not substitute for the architect's prior-row-art reconciliation and live review.

Before route playback, freeze/import the access and medicine candidates, run the original art checkers, compile production sections with `node tools/compile-places.mjs`, then run `node tools/verify-places.mjs`. That command physically follows every occupied-room/floor target and returns to spawn using ordinary movement/interact commands for every animal. It checks rendered support, source-slab openings, actual closed/open leaf poses and section retirement. Only a completely successful run writes `verified-routes.json`. The browser workbench refuses saved paths from a different access commit, navigation hash or compiled-scene manifest hash.

Use the actual title's Play/Options and main-menu controls to review production flow. The separate review controls offer Map and Animal selectors plus **Open selected map**, which performs normal exit/selection/loading into a fresh visit. The three landmark maps then offer **Start verified out-and-back route**. Playback feeds ordinary move/interact commands into the active runtime while its own animation loop renders. It never sets position/elevation, resets a player, calls a floor selector or advances a second clock. It starts only near the verified spawn; after manual movement, walk back or reopen the visit.

**Pause route and visit**, **Resume route**, **Stop route** and **Return to selection** are native buttons suitable for the supported Chrome computer-use controls. A gameplay key or pointer stops playback for manual takeover. Missing source sections wait under normal stream protection. A stall pauses for inspection; changed/dead visits, disposal and the 15-minute route deadline cancel movement. The page has an actual 30-minute disposal timer. Reload deliberately for another review; no OS helper is launched by this workbench.

The visible status reports current leg/completion, native elevation and location. The metrics panel reads the actual runtime's section loads/peaks, geometry/material counts, renderer draw calls/memory, observed frame rate, CPU timings and renderer identity. It also lists authoritative street pickup consumption. These are observations from the live renderer, not prerecorded frames. Do not treat an idle or paused frame sample as moving-game performance.

**Save visit JPG** captures the actual visit canvas in the next `onSnapshot`, immediately after render, with `preserveDrawingBuffer` still false. The downloaded JPEG has a unique `tinderbox-review-01a17e9b-<place>-<character>-<timestamp>.jpg` name. It contains the rendered WebGL view rather than browser/profile chrome; the product HUD remains a separate DOM layout review. No generated illustration or rerender substitutes for this capture.

For manual landmark review: select goat/horse/bear; approach the visible entry from the grounds; use its contextual Open control (E/Space in exploration); walk through the actual opening and along the tread surfaces to the next occupied hall/gallery; use Overview/Follow without changing coordinates; descend and return outside. The route status names each target hall. Exact doorway/stair directions and source-local coordinates will be appended from the accepted access geometry and successful route evidence. No decorative crown or unsafe roof is a destination.

For manual Catalogue Street review: open each animal, walk over powder at (17,21), healing at (21,23) and inversion at (27,21). HP/effect feedback, `pickup-used` state and disappearance must agree. At full HP, medicine stays available. Repeat crossing cannot reuse an item. Verify pouring while collecting, once-only inversion, tool/aim preservation, pause, reset and return. Ground presentation is frozen at medicine `988b4aca32343c9f2e566db74bb018c705820742` and consumes the same authoritative snapshot as the HUD.
