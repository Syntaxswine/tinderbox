## Application and UI

`src/content/places.js` exports frozen `PLACES` in the agreed order: Catalogue Street, New York, Administration, Horticulture. `src/content/characters.js` exports frozen `CHARACTERS` (`goat`, `horse`, `bear`) and the tunable initial goat choice.

The application owns `title -> menu -> loading -> visit`, selected character, cancellation, errors and disposal. `mountTitleScreen({root,onStart})` uses the title container. `mountMainMenu({root,places,characters,selectedCharacterId,onSelect,onSelectCharacter,onBackToTitle})` uses the selector container and receives loading/error/selection updates. No renderer is created for title or selector. The chosen animal passes into every visit, including the street. Selection changes are accepted only in the selector. Visit exit restores the selector and selected-card focus; Back to Title restores Play focus. Duplicate requests are coalesced; stale async completions dispose themselves.

`src/main.js` exports `currentApplication` for combined browser review. Its `visit()` exposes `snapshot()`, `metrics()`, `dispatch()` and `advance()` for actual input and resource observations. It exposes no player relocation or floor-teleport API. Leaving a map disposes queued commands without advancing gameplay. A failed cleanup operation does not prevent the remaining resource owners from retiring.

`mountUI` receives `mode`, `placeTitle`, `onExitToMenu`, existing `onCommand`, and connected `onZoom`. Runtime handles `view-overview` / `view-follow`. Explore snapshots retain the v1 shape and add `mode:'explore'`, `player.characterId/species/height`, `elevation` (feet in metres), native `level`, human `locationLabel`, `interior` and optional `interaction:{label,enabled}`. `interact` changes a nearby portal only when safe. `navigation` records view, authoritative portal states, waiting-for-section status and resource counts. No floor teleport is exposed. Fire/combat commands are rejected by the exploration model; Catalogue Street keeps its existing rules.

## Navigation and rendering

Complete lightweight support/ceiling/barrier/portal metadata stays resident. Actual tread top polygons provide stepped heights; source floor polygons and access openings provide floors and holes. Swept native body movement, per-step rise limits, footprint support, headroom, closed/open leaf collision and edge protection apply before accepting motion. Missing visual neighbours block crossing until their source sections are ready. Focus loss clears movement and pauses; reset restores initial portal state.

The original factories execute in the offline compiler, never as a monolithic runtime landmark. Their exact geometry attributes, physical UVs, materials and native matrices become independent 16m spatial/native-height sections. Floor-opening boundaries are separately derived clipped slabs; raw factories remain byte-identical. Runtime uses shared instanced geometry with reference counts, four concurrent section jobs, a hard 192-section limit and load/retire hysteresis. Exiting or selecting another place releases owned section resources, including late completions. Overview is a clearly identified native-footprint plan and releases detailed sections. Interior view clips upper geometry at shoulder height while navigation remains authoritative. One host Three namespace/renderer serves the active visit. No landmark fire grid is allocated.

Unique floor fragments with matching material, attributes and native matrix are batched per section by copying exact source triangles and UV values. The raw extraction diagnostic preserves all source triangles: New York 249,708; Administration 614,274; Horticulture plus terrace 1,154,330. Batching reduces Administration's unique geometry buffers from 1,670 to 449, and Horticulture's from 2,380 to 555. These are offline resource counts, not measured frame-rate claims. Portal closing bounds cover all leaves and both their actual closed/open poses. Solid cumulative entry steps expose only the highest unburied tread at a point.

`tools/compile-places.mjs --source-only` is a private extraction diagnostic under ignored `artifacts/TB-024/source-sections`, explicitly marked non-playable and rejected by the production loader. Production section compilation requires the frozen artist access candidate. It will not silently package an exterior-only substitute for the requested interiors.
