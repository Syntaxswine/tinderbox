# Catalogue Street automatic pickups

The architect's milestone-08 addition resolves the earlier six-button UI handoff. Drug/medicine use comes from walking over a world item. The old diagnostic `drug` command remains for existing fixtures; production UI needs no manual drug key or extra action.

Snapshot v1 adds top-level `pickups:[{id,kind,x,y,radius,consumed}]`. Kinds are `powder`, `healing`, `inversion`. Coordinates are ground metres, matching the street's world X/Y (renderer X/Z); elevation is ground zero. IDs are stable and unique across scene objects. Retain consumed records and hide their presentation. The model emits `pickup-used` with `pickupId`, `kind`, `actorId`, position, tick and event ID exactly once per item lifetime. Existing `drug` events additionally identify `source:'pickup'` and `pickupId`. UI continues to read authoritative health/effect timers. Exploration snapshots contain an empty pickup array.

Artist API: `createMedicinePickups(THREE,{materials,textures}) -> {root,update,dispose}`, with `update(snapshot.pickups,{worldTime,paused})`. Borrow the host namespace, material/texture inputs and native metre coordinates. Ground art never applies effects or destroys authoritative items. The caller owns attaching the root and calling disposal. Only the street uses this presentation. Await the exact artist commit/module path for immutable intake; no source art is replaced by code in this candidate.

Explicit prototype defaults: radius .22m (validated .10–.50m), at most 64 items, one existing dose per item, full-health healing left unconsumed, and timed effects refresh to the existing duration without stacking multipliers. Pickups apply at the fixed-step boundary after accepted movement; movement speed/inversion for that step was already evaluated, so a new effect changes the next step. Collection leaves raw movement, aim, held tool and pouring untouched. Healing uses the existing HP clamp. World items neither require nor change legacy inventory stock.

Detection sweeps every collision-accepted segment, orders encounters by travelled distance then stable ID, and requires clear line-of-reach. Requested movement endpoints and HUD overlap do not participate. Pause/death cannot collect. Reset restores all declared items and defers collection until the next active step, so the restored snapshot is observable. No item respawns during an ordinary visit.

Current prototype street placements: powder `street-powder-west` at (17,21), healing `street-healing-centre` at (21,23), inversion `street-inversion-east` at (27,21). These are authored test placements on the open street, not progression/balance commitments. Source validation rejects duplicates, malformed values, out-of-bounds or obstructed items before simulation starts.
