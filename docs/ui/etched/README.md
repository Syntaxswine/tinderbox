# Engraved newspaper menus and oil lantern

UI candidate on `codex/ui-design`, 2026-10-28, built on `0c52b7f08a8f4bf5e93502810a2751f5de63d444`. The commit containing this handoff is the candidate; the delivery reports its exact SHA. Architect review and promotion remain required.

## Result

The existing Eastlake wood frames now hold warm paper, a centered newspaper masthead, double rules, illustrated menu rows and lettered tool notices. A pointing hand, open book and quill replace the pause menu’s diagram-like marks. The control deck uses detailed engraving-style object illustrations: pocket watch for Pause, wooden fingerpost for Invert, compass for movement, and a tool chest for Tools. Labels and stock remain readable text beside the illustrations.

The user’s correction is applied: the third tool is **Oil lantern**, shown as a tin-and-glass hurricane lantern with a wire carrying bail. Its existing **Throw** action and stock remain authoritative. Compatibility IDs `molotov` / `molotovs` are unchanged. Native selection and Throw were checked in the actual combined scene: the label read Oil lantern and stock changed from 4 to 3.

This is the UI portion of that correction. **Artist/coder follow-up:** replace the carried and flying bottle models with an oil lantern, including the matching projectile presentation. This candidate does not change `src/art`, `src/runtime` or `src/simulation`, and adds no fuel, blast, flight or balance rules. The old bottle cell remains in the original atlas bytes but is never displayed.

Exactly three persistent buttons remain on each side of the joystick. Picker selection, independent input pointers, Pour/Stop, pause authority, focus trapping, full/empty stock and disposal behavior are retained.

## Assets, type and provenance

The [asset record and full generation prompts](../../../assets/art/ui/engraved-plates.json) contain dimensions, byte lengths, SHA-256 values, frames, sources and the user’s lantern correction.

- [Original engraving atlas](../../../assets/art/ui/engraved-atlas.png): 1402 × 1122, 1,994,109 bytes, SHA-256 `e1be50ce8a5afc92e535730d24ac9ad19ac416119275cb345eafe4c8cfe6502a`.
- [Oil lantern plate](../../../assets/art/ui/engraved-oil-lantern.png): 1254 × 1254, 1,565,428 bytes, SHA-256 `ff847341bcab4cf3cec536cea9a3b489b82ab161ff4fd55ca03e7253d8a0ac85`.
- [System-color vector plates](../../../assets/art/ui/engraved-outline-plates.svg): original editable contour/hatch drawings, including an oil lantern, used only in forced colors.

Both PNGs were generated with the **built-in image_gen tool** for this project. They preserve the exact generated bytes and alpha. Read-only alpha analysis informed native SVG viewports; no bitmap crop, recoloring or re-encoding was applied. Explicit per-instance clip paths prevent neighboring atlas illustrations from appearing in letterbox margins. Stock/timer-only updates retain the existing image node. The two PNGs total 3,559,537 bytes; handset transfer/decode performance has not been measured.

Besley and Old Standard TT remain local, with all nine pinned font/source/notice hashes and OFL notices unchanged. These are modern period-informed type choices, not an exact reconstruction of an 1893 typeface.

The [Illinois State Museum Eastlake page](https://museum.state.il.us/muslink/art/htmls/ms_eastlake.html) informed the incised/geometric wood framing; its text was read and no museum imagery was copied. The [existing primary print and wayfinding study](../exposition/README.md), including the 1893 Flinn guide, supplies the centered serif/rule/sign context. Newspaper layout and sign plates are original game adaptations, not newspaper facsimiles or a claimed standard historical sign system.

The Farmyard source pin remains `30a3b8cae5f36bb0c1df3685b7fba16f701c2083`. Existing donor control grouping, geometry, local map frame and timber imports remain intact. No new donor file was imported or donor checkout modified. Existing rights uncertainties remain as recorded; provenance is not a license grant.
