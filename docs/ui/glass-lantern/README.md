# Glass oil lantern

UI candidate on `codex/ui-design`, 2026-10-28, based on `d81ff8fa6cfdd0c2bc2aaa77fb8781bfd4f708af`. The commit containing this record is the candidate; the delivery supplies its exact SHA. Architect review/promotion remains required.

The user requested a glass oil lantern. The replacement engraving has a broad clear-glass reservoir, visible oil level and submerged wick, a tall clear chimney, small brass burner and thin wire carrying bail. It keeps the monochrome newspaper engraving style, Eastlake wood frames and existing typography. The glass is expressed through contours, reflections and an oil meniscus in the illustration; this does not implement a 3D glass material.

The tool still displays **Oil lantern**, uses **Throw**, and retains internal `molotov` / `molotovs` IDs. Native clicks in the combined scene selected the lantern and changed stock from 4 to 3. This pass changes no gameplay, input, layout or camera code and introduces no shattering or balance rules.
