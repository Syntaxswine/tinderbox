## A bounded exterior location

Use a portion of the paved approach immediately **east of Administration**, before the western end of the Basin. The named building, water edge and nearby large-building blocks provide a traceable setting without attempting the entire fair. The map supports these relationships:

- Administration is west of the Basin.
- Machinery occupies the southern side of this local ensemble; Agriculture is to the southeast.
- The published plan distinguishes building blocks, water and circulation space, with indexed names and entrances.

These observations locate a scene; they do not establish the final day's built conditions or construction details. Preserve the source's north reference and its relative relationships when the architect selects a trace. The scan is a folded, printed sheet, not a georeferenced survey.

The existing 20 x 16 m mechanics-test extent can serve as a **game crop** within such an approach. It is not the measured extent of the forecourt, and a whole exhibition building must not be shrunk into that rectangle. Partial facade/background forms and off-screen landmarks are possible adaptations for later approval. Water placement, boundaries and solid footprints still need an architect-approved layout before implementation.

The arithmetic conversion of the printed scale is 1:6,960 (`580 feet x 12 inches/foot`). Using modern game-unit conversion, 1 cm on an undistorted original corresponds to 69.6 m. These are derived conversions, not new historical measurements. A web preview's displayed physical size is arbitrary: use the sheet's scale bar and locally check both directions if later tracing is authorized. Fold distortion and print reduction preclude claiming metre-level accuracy from these images.
