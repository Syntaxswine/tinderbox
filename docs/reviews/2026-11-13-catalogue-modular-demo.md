## Runtime and combined gate

Required evidence includes the real input/stair routes, tools and automatic pickups, suspicion versus direct witnessed ignition and pistol cover, finite thermal accounting, normal real-time pacing, reset/disposal, selected nested-path package closure, and the ordinary repository checks.

The final-art live-loop control measures 58.29 Hz while moving without fire (267 frames / 4.56 wall seconds / 4.58 world seconds), and 16.22 Hz with a growing grass fire (50 frames / 3.02 wall seconds / 2.83 world seconds, 88 burning patches). Fire-frame p95 is 136.3 ms, worst 201 ms. Neither window adds dropped simulation time. Actual rendered-surface aiming, native match ignition, keyboard/mouse release, DOM-blur pause/resume and reset pass. Headless tab activation alone does not emit the required OS blur; it is a failed driver stimulus, not evidence of OS-level focus acceptance. These measurements are not mobile results or an isolated GPU benchmark. The roughly 30 fps prototype fire target is **unmet**.

The later final-source raw browser-rAF run supersedes that completion-timestamp performance window for release assessment: quiet 56.7618 Hz (264 frames, 4.6334 rAF / 4.63333 world seconds, p95 33.1 ms, worst 50 ms, no window drops); growing fire 10.3168 Hz (39 frames, 3.6833 rAF / 3.5 world seconds, p95 300 ms, worst 366.7 ms, 0.1832 dropped seconds). Initialization is 31.2554 seconds, with 9.8834 initial global dropped seconds. The observed renderer is RTX 3080/D3D11, Edge 157, Three 180. The functional checks pass, but this fire pacing is a **publication blocker**, not performance acceptance.
