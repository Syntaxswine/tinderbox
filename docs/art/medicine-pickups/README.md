# Medicine ground props

Three grounded, reusable presentations for the accepted walk-over medicine requirement: a folded powder packet, a medicine jar and an octagonal inversion tin. They reuse the project's existing materials and control marks. All three fit the current 0.22 m default pickup radius, without scaling the native animals.
