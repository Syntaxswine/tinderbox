## Frame and ownership

`createFireRealism(THREE,{quality:'reference',maxCells:4096,maxRays:256,maxBuildings:64})` returns `{root,update,reset,dispose,diagnostics}`. `quality:'optimized'` throws until a legitimate reference is visually accepted and frozen. Input grids support65,536 cells; emitting/history sources are bounded to4,096, rays to256, building groups to64 and jet-smoke records to384. Overflow throws rather than dropping visible fire. The defaults and all resource limits are explicit diagnostics. The host supplies its shared Three r180; the factory creates no renderer, loader, fetch, absolute donor path or simulation state.

All effect positions use native metres at an identity root: ground(x,y) maps to Three(x,height,z). `update` consumes the detached milestone-11 v1 frame, existing cell states, native anchors and authoritative resolved discharge. Camera arrays are column-major. `fieldUniforms` and optional `opaqueDepth` textures are borrowed, never cloned per frame or disposed by the effect. All matrices/settings copied into owned uniforms are detached. Repeated update/reset uses the same one geometry, one material and two owned data textures; the three spill lights are bounded. Disposal is idempotent and frees only owned GPU resources.

Motion uses `worldTime`, never wall/player time. Pause freezes emission and the clock while accepting the current camera/depth; reset, rewind and receipt-generation/reset clear source histories. Spent fuel stops flames and its3.2-second smoke tails expire. A torch requires **selected tool `torch`**, a finite lit timer and a supplied actual torch-tip anchor. Retained lit inventory state cannot display an unequipped torch. Runtime event receipts remain external to this art factory.
