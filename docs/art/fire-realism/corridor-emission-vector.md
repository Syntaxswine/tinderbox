This additive source experiment wraps the immutable f938 corridor04 control.
The [source note](../../../workbenches/art/fire-realism/corridor-emission-vector/README.md)
and [provenance](../../../workbenches/art/fire-realism/corridor-emission-vector/provenance.json)

palette evaluated on clamp((Tproxy-1.5)/1.5). Filter the full emission vector,
then multiply6 and existing reaction/source/contactG once; legibility stays once.

andrawF, extinction/alpha/blend, light/depth/geometry/clocks and common HDR
Neutral/exposure1 remain frozen. No F<=1 clamp or fitted gain/exponent sweep.

The new factory delegates f938 and mutates only private shader text after ALL
92ownedmaterials match the complete frozen5898B/ea335a90 control. Six substitutions
have a byte-exact full inverse; refusal disposes the original effect. The three
data API exports are identical aliases, so the original single store and193
resources are reused. The closure manifest measures both additive modules and
retains every original source/resource identity. ParentLF changes append only
the three explicit newfilename rules.

Pure/source/mock checks establish the inverse, sharedfetch/rawmix, vectorordering,
G0/fractionalG/F>1 expectations, subdivision and refusal/disposal/alias behavior.
They do not execute GLSL, prepare/decode data or construct a factory/renderer.
Native compile, useful attached channels/height/motion, cost and allglobalgates
remain for ROOT/UI review. Raw/admitted/inputE/referencefalse and frame97/50
positiveF/98zero remain; no upperoverhang/nativebounds acceptance is implied.
The original dataset/source/publishedmatches and every old control are preserved.
