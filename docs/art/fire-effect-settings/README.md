# Independent furnished-house effects: artist candidate

The artist-owned implementation starts at contract 5bcd95dc / frozen code 25095656. The accepted expensive reference ee1d10b and its movie remain unchanged. Native structural modules remain 1 x 1 x 2.12 m, with 2 m walls and .12 m slabs. No geometry, floor height, UV density, simulation module, production route or donor file changes.

Pass view.effects={flames,smoke,lighting}; missing or nonboolean keys default true. Each channel branches before its own preparation/generation. Flame-off omits tangent/radius assignment and connected flame envelopes. Smoke-off omits all smoke calls, including preheat. Lighting-off omits clustering and zeros the existing six owned lights. Char geometry, heated materials and debris still consume authoritative state. World-time phase always comes from the current frame, including re-enable/return at the same revision.

Ownership and simple finite geometry validation run before culling. Known hidden cutaway flame levels/roofs skip their envelope work. Ceiling fire keeps its actual lower level. Current falls/landed footprints outrank retired source provenance. A hidden base can retain smoke; its complete plume has an independent camera bound. Arbitrary wind samplers without declared ambient/calm control metadata retain uncertain effects. The bounds include full support/anchor extent, pitched roof adjustment, the shroud's clamped drift/rise and Gaussian support. No occlusion rays or new simulation rules are added.

Connected-plane groups are classified cheaply. If one member may be visible, the entire group remains preparation context so its union stays identical. Off-camera context generates no splats. This deliberately retains some work. The reference support-anchor search is shared by smoke and local lighting to preserve their exact positions independently of flame settings. It can remain for off-screen illumination; its calls/cache computations are counted separately from flame-only envelope preparation. With lighting off and the entire group outside, that anchor search is skipped too.

The additive diagnostic schema is in art/source/furnished-house/api.json. diagnostics().effectWork supplies source reason counts, per-channel counts, generated/submitted splats, active lights and actual preparation/generation calls. Reason counts overlap across independent channels and must not be summed as a partition. representedSamples now explicitly means a valid mapped source, including deliberate omissions. missingSamples still means malformed/unmapped ownership or invalid support; settings/camera cannot convert it into a successful cull. inspect().emitters identifies channel eligibility, context and omissions. Intentionally skipped emitters may retain their supplied anchor and null flame radius.

Run node art/source/furnished-house/check-effects.mjs. It compares actual splat positions/scales/phases, connected envelopes and local lights against immutable 25095656, tests all eight masks, source immutability, disabled work, cutaway/underside, camera-away/return, visible plumes with hidden bases, ambiguous input and real 88 s fall ownership. The baseline source is read from Git objects into ignored artifacts/helpers/fire-effect-visibility/controls; only imports are rebound to immutable controls/shared local dependencies. No server or GPU/browser helper is launched. The architect owns normal-zoom combined JPGs, all-on pixels, the eight-mask hardware timing and promotion.
