# Art documentation

Start with the [shared modular art workflow](shared-modular-art-workflow.md) for
reusable 3D assets across Nautilus Engine games. It defines the stock tile,
procedural assembly, the concept and sculpting stages, painterly skins, runtime
review and extra resources for the main character, which may be a person, creature,
place, object or effect central to the game or story.

Individual asset directories contain their designs, sources, exports, previews and
validation records. The [painted stockyard workers](stockyard-workers/README.md)
provide one character clothing example of the painted surface approach.

For Tinderbox intake and delivery, also follow the repository's
[assignments and promotion process](../workflow.md) and
[pinned source baselines](../source-baseline.json).
