# New York State Building, 1893 — TB-022 candidate

A separate exterior landmark, with the original plan's stepped rear, curved end colonnades, repeated facade bays and paired capped roof towers. The facade is 47 m wide; the complete ground envelope is 70.5 m wide. Tower caps reach 33.5 m. It retains the shared 1 m grid and native bear scale.
