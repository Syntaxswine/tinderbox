## Coder: one witness

Use one existing civilian at Bell & Alder in an opt-in test on Catalogue Street. Keep the six tool buttons, movement controls and current contextual door and pickup actions. The ordinary visit, Ashland replay and other maps keep their current behavior. This trial adds no inventory, pursuit or citywide stealth rules.

- A clear sighting of the player carrying the lantern picked up from the room leaves a memory of the player, position and world time. Carrying the lantern out of sight leaves no memory.
- When the witness notices a nearby fire that started after and near a fresh sighting, the witness shows suspicion. Record the prototype's time and distance limits. The response should work even when the witness did not see what caused the fire. An expired memory or unrelated fire does not count; ordinary spread does not repeatedly increase the response.
- Seeing the player actually start a fire gives a stronger, distinguishable alarm even with no lantern memory. Alarm takes precedence over suspicion. A tool press, failed ignition or subsequent spread is not proof the witness saw the player start it. Exercise real match ignition first; record what other sources the test covers.
- Demonstrate both outcomes using the actual shop and fire rules. Exercise a missed sighting, memory expiry, failed ignition or spread, and reset. Check sightlines against solid occluders, keep the existing controls, and verify test isolation. Include the exact commit and steps, with a normal zoom browser capture if available. This test does not change ignition, fire spread or movement tuning.

## Artist: first period uniform

Start with one modular Chicago municipal beat patrol uniform circa 1893 as the first set for future street responders. The witness uses existing civilian art. Keep municipal street clothing distinct from the fair's Columbian Guard. Start from a documented hat, coat, trousers and belt or badge, adapting footwear and fit to the first existing native animal rig without changing body size, animation or attachment points. Record how to refit the pieces for other animals.

Use period photographs and dress descriptions where available. Start with the [1893 municipal report finding aid](https://guides.lib.uchicago.edu/ChicagoStudies/PoliceandFD), the circa-1895 city police photograph reproduced in the [Town Hall Police Station landmark report](https://occprodstoragev1.blob.core.usgovcloudapi.net/lsmatterattachmentspublic/7513b8f2-11ae-40c7-8ff2-ffcd87713128.pdf), and the period [Marquis handbook's police section](https://upload.wikimedia.org/wikipedia/commons/d/d8/Marquis%27_hand-book_of_Chicago%2C_a_complete_history_%28IA_marquishandboo00marq%29.pdf). Log the edition or date, item or page, rights and what supports each design choice. Distinguish monochrome evidence from inferred fabric color. Keep uncleared reference images out of shipped assets.

Deliver an evidence-backed silhouette first, followed by an art-only candidate with source notes and JPGs at close range and at normal night street zoom beside an ordinary civilian. The uniform is a separate future intake; it adds no gameplay or UI to this test.
