# Burning-trail bear prototype

The editable master is procedural geometry in [bear.js](../../../../src/art/bear.js),
with the shared palette in [materials.js](../../../../src/art/materials.js).
The adjacent prototype.json records the current source hash, nominal dimensions, and provisional status.

This is a mechanics-test character. The user has not approved this visual direction; the next art pass must use actual Farmyard assets as its foundation. Neutral forward is ground +X; ground +Y maps to Three.js +Z. The model has five equipment poses and a small player-clock gait. Rendering follows the supplied player.radius. During active discharge, the held lance/torch hides conservatively when its cosmetic muzzle lies outside the supplied connected shape. Dimensions and anchor offsets remain unchanged.
