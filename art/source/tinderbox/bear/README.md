# Burning-trail bear prototype

The editable master is procedural geometry in [bear.js](../../../../src/art/bear.js),
with the shared palette in [materials.js](../../../../src/art/materials.js).
The adjacent prototype.json records source hash, nominal dimensions, and status.
No layered bitmap or finished character is implied.

Neutral forward is ground +X; ground +Y maps to Three.js +Z. This prototype has
five equipment poses and a small player-clock gait. Its silhouette and collision
envelope need combined architect/coder review before gameplay acceptance.
