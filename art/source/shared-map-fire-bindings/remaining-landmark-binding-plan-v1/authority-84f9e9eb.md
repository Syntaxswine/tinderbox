# Prepare compact bindings for the remaining landmarks

The twenty roof-fitting assets are source accepted. Reuse the existing artist
checkout for one **source-only format/packaging proposal** for Administration
and Horticulture. Actual conversion/export and runtime installation still wait
for New York's runtime/visual/performance gate and a reconciled consumer.

Build on the existing remaining-material, geometry, measurement and
vegetation/pane evidence; do not repeat the large geometry or mask calculation.
Propose a compact representation of original owners, material/profile recipes,
quantity certificates, source ranges/transforms, attachments and local damage
identity, using shared definitions and bounded section shards. It must be
self-contained and preserve native units, original geometry/UVs/IDs, single
canonical ownership and reviewed provenance. A file catalogue is not gameplay.

Report actual source counts and estimated bytes derived from existing data:
shared dictionary/library, per-section records, largest shard, initial metadata
and expected nearby-section loads. Show a few representative source-only
records for a wall, furniture owner, pane/frame and plant owner. Explain how
they could feed the existing common adapter without a second renderer,
simulation or per-map weapon callbacks. Avoid generating another full
105,310-row table merely to estimate its size.

Keep accepted quantity references distinct from runtime stock; include exact
recipe/certificate references rather than rounded substitutes. Do not infer
profiles from colour or authored material tokens. Preserve inert water and
dry-ground navigation, local glazing retirement and original hinges/attachments.
Do not invent joins, anchors, geometry repairs, new burn profiles or a moisture
solver. Identify which proposed fields need a common consumer decision.

List the unresolved plant/glass support and envelope cases explicitly, including
the eight schema/live-path gates, 76 bed/ground attachments, two fern crowns,
66 finer plant envelopes and four oblique sheet/frame cases. Source planning
must not relabel these as accepted bindings or silently omit the geometry.

Deliver one short proposal (main prose at most 700 words), compact examples,
input pins/counts and concrete remaining blockers. Verify paths/references,
scope and deterministic count/size derivations; no invented runtime tests.
No new geometry export, full authoring table, native compiler/world/trial/graph,
mask recalculation, renderer/JPG, benchmark, build, dependency, helper, checkout
or branch. Preserve prior evidence; scoped commit/push then stop for review.
