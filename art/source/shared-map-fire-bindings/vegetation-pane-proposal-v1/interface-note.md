# Interface note for architect/coder relay

This note is the coordination artifact for the source proposal. Coder draft
5478eb5cbb4c701ce88e3642c58a13eb7547f282 is pinned beside this file. It accepts
no general vegetation/pane schema. No runtime, compiler or binding change is
requested or installed by this checkpoint.

The coder Markdown is a verbatim snapshot. Its relative references retain the
original docs/engineering/shared-maps context at the pinned coder commit;
source-reference checks use that Git tree. Authored checkpoint links resolve
inside this source package.

- Keep one original/proposed logical owner account. Local frond patches debit
  exact normalized area shares of its finite budget; fruit/flowers add zero
  independent stock and follow fixed original local patch selections (all-of).
- Local damage masks retain original source part/range/matrix provenance.
  Source-local native-scale masks are not canonical native IDs. Admission
  requires the original grid/compiler and a reviewed mapping.
- Zero-fuel glass still screens physically. A local hit cannot retire a whole
  dome/gallery sheet. Thin-sheet front/back/edge contributions must agree;
  four oblique captured sheets still need a pinned original sheet frame.
- Sheet support and local breakage are separate. Original component boundaries
  and fixed local frame-contact ports remain immutable. A middle mask may use
  an intact path inside the same original component to those ports.
- The future consumer must exclude retired/broken portions, preserve local port
  liveness, and handle loss of all valid paths. No path may bridge another
  disconnected pane or remap to a different surviving frame. Glass and plants
  cannot brace the greenhouse; contact is not an approved fastening or anchor.
- The four representative paths prove pristine within-facet connectivity only.
  Dynamic retained-mask paths, birth/support behavior and canonical native
  admission remain unimplemented. Full authoring export is separate.
