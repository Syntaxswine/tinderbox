# Preserved source-calculation evidence

Ten deterministic gzip archives preserve 201,206,429 bytes of completed
source-only calculations. The manifest records raw and compressed lengths and
SHA-256 values. The package manifest also pins the original calculator archive.

This is review evidence, not a runtime/binding or full authoring dataset.
The raw first-pass per-mask direct-contact exception labels do not establish
unsupported interior glass. The compact current proposal and representative
same-original-component paths supersede that interpretation.

The completed calculator source is preserved byte-for-byte in
original-calculator.py.gz. The adjacent ../calculate.py retains its calculation
method, compares a default read-only rerun with these archives, and directs an
explicit --save-review run to scratch-calculation-output rather than overwriting
the compact checkpoint. No second full calculation was needed for this handoff.

Default bounded checkpoint checks:
~~~powershell
python -B art/source/shared-map-fire-bindings/vegetation-pane-proposal-v1/review.py
~~~

Optional full source-calculation reproduction:
~~~powershell
python -B art/source/shared-map-fire-bindings/vegetation-pane-proposal-v1/calculate.py
~~~

Neither command runs native simulation, a world, a factory or a renderer.
Current schema, support/grounding and live-path limits remain explicit.
